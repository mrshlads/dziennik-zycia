# Dziennik życia

Osobisty dziennik dobrostanu, umożliwiający obserwowanie zmian w życiu i analizowanie codziennych doświadczeń.

**[Uruchom aplikację](https://mrshlads.github.io/dziennik-zycia/)**

## Funkcjonalności

- **Kalendarz** – wpisy przypisane do konkretnych dni.
- **Koło życia** – hierarchiczne kategorie, podkategorie i średnie ważone.
- **Dziennik zdarzeń** – rejestr przyjemnych i nieprzyjemnych doświadczeń.
- **Big Picture** – wizualizacja zdarzeń w różnych skalach czasu.
- **Porównania** – analiza zmian ocen koła życia w czasie.
- **Import i eksport JSON** – kopie zapasowe i przenoszenie danych.

## Technologia

HTML, CSS, JavaScript, SVG, IndexedDB i Service Worker.

Aplikacja PWA działa offline i może zostać dodana do ekranu początkowego iPhone'a lub iPada. Nie wymaga backendu ani instalacji z App Store.

## Prywatność

Dane są przechowywane lokalnie na urządzeniu. Aplikacja nie przesyła wpisów na serwer. Zalecane jest regularne wykonywanie kopii zapasowych JSON.

Import kopii zapasowej zastępuje bieżące dane. Automatyczna synchronizacja między urządzeniami nie jest dostępna.
